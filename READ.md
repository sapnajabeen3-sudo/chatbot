# 🤖 AI Chatbot Using Ollama 3.2.4

A simple AI chatbot built using **Ollama 3.2.4**, Python, and Streamlit.  
This project was developed as part of my internship at **SkillerzHub** to explore Large Language Models (LLMs) and local AI application development.

The chatbot runs AI models locally using Ollama, allowing users to interact with an AI assistant without depending on external APIs.

---

## 📌 Project Overview

Large Language Models have transformed the way we interact with AI systems.  
In this project, I created a chatbot application that connects with Ollama's local LLM environment and provides intelligent responses through a simple and interactive interface.

The main goal was to understand:

- How LLMs can be integrated into applications
- How local AI models work
- Building user-friendly AI interfaces
- Practical implementation of Generative AI concepts

---

## ✨ Features

✅ AI-powered chatbot responses  
✅ Local LLM execution using Ollama  
✅ Interactive Streamlit interface  
✅ Fast response generation  
✅ Privacy-focused local processing  
✅ Simple and beginner-friendly implementation
